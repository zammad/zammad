# Contributing to Zammad

We love contributions, and we want to be clear about which ones we can take in.

## Bug fixes and small changes

Bug fixes, small improvements and changes that do not alter the behavior of Zammad are always welcome.
Open a pull request on GitHub with a clear description of the problem and the solution, and reference
the related GitHub issue if there is one. These are the contributions we merge most often.

## New features and larger changes

Please do not start with a pull request for a new feature, an enhancement or a larger change.
Our product owner deliberately selects which features make it into Zammad, so that the product
stays focused and does not bloat. A pull request for a feature that is not on the roadmap cannot be
merged, no matter how good it is, and we do not want you to waste your time.

The way a new feature gets into Zammad:

1. Check the [feature requests](https://community.zammad.org/c/feature-requests/6) in our community.
   If a request for your idea already exists, add your use cases and user stories there.
   Otherwise open a new one and describe the problem you want to solve and the user stories behind it.
2. Feature requests with enough demand (votes, likes, discussion) are picked up by our product owner
   and turned into user stories for the product and the team.
3. The feature is then implemented by the Zammad team. In most cases we build it from scratch, so an
   existing pull request serves as a reference rather than being merged as it is.

## Other ways to contribute

- Found a bug? Search the [GitHub issues](https://github.com/zammad/zammad/issues) first and open a new
  one if it was not reported yet.
- Questions about the source code? Have a look at the [Developer Manual](doc/developer_manual/index.md)
  or ask in the
  [development category](https://community.zammad.org/c/all-stuff-related-to-the-development-of-zammad/8)
  of our community.
- Documentation: open a pull request in one of the
  [documentation repositories](https://github.com/zammad?q=documentation).
- Translations: register at [translations.zammad.org](https://translations.zammad.org) and translate away!
